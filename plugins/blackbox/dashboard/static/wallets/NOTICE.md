# Wallet logos

Shown next to wallet events so a person can see at a glance which wallet Blackbox protected.

## metamask.svg

A flat, front-facing rendering of the MetaMask fox, projected from the 3D model in
`@metamask/logo` 4.0.0 (`data/fox.json`), unmodified colours and faces.
