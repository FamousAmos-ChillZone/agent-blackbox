How it works

Every action is checked before it runs

Each time your agent is about to read a file, run a command or send something, Trader Shield checks it on your own machine first. Nothing about your wallet ever leaves the machine.

1 · The agent acts

A tool call or command

Reading a file, running tar or cp, writing or sending text.

2 · Sees the files

Terminal or file tool

Finds every path a command touches, even inside archives and copies.

3 · The vault

Is it your wallet?

Recognises your wallet's key store in every browser profile.

4 · Secrets

Phrase or key?

Spots real seed phrases by their checksum, and private keys by their label.

5 · Leaving?

Sent off the machine?

A secret in an upload, request or message is stopped.

BlockedIn block mode the action never runs, and your agent is told why.
FlaggedIn audit mode, or for cases that are sometimes fine: it runs and you see it on the dashboard.
Never loggedSeed phrases and keys are scrubbed from Blackbox's own records, always.
What it stops

Three ways a wallet gets emptied

Steal the vault
1A poisoned package or web page tells the agent to "back up the browser profile".
✓Trader Shield recognises your wallet's vault inside the archive and stops it.
2Without it: the vault is uploaded and cracked offline.
Capture the seed phrase
1A fake "recovery" or "support" flow asks for your 12 or 24 words.
✓Trader Shield recognises a real phrase by its checksum and stops it leaving.
2Without it: whoever has the words owns the wallet.
Lift the trading key
1An injected instruction asks the agent to "share the config for debugging".
✓Trader Shield recognises the private key and stops it being sent.
2Without it: the key signs transactions for the attacker.
The settings

What each switch does

All in Blackbox Settings → Trader Shield. Changes apply on the next action your agent takes.

Engage Trader Shieldoff by default

Turns the wallet protections on. While it's off, Blackbox doesn't flag or block anything wallet-related and the Trader Shield panel stays hidden. Seed phrases and keys are still kept out of Blackbox's logs either way.

Wallets to protectpick the ones you use

Only the wallets you tick are guarded. Blackbox finds them by checking which folders exist in your browser profiles; it never opens a wallet. The dashboard panel lists what it found.

Protection mode: Audit or BlockBlackbox-wide setting

Audit records and flags. Block stops the action before it runs. For real protection, use Block once you've seen a day of flags.

Protected files.env · ~/.ssh · *.pem …

Your own list of sensitive files, such as the config where your exchange API keys live. Reads through file tools are flagged critical and blocked in block mode.
